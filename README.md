One line roasting a smart fridge: "My smart fridge updated its firmware and now judges my 2 a.m. snacks in push notifications." The program writes that line to `/output/entry.txt` (91 characters, within the 200-character gate), checks its length, and reads it back to confirm it round-trips.

## Run it

```sh
node main.ts
```
